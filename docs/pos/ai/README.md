# POS AI Execution Pack

This folder translates POS planning docs into executable AI tickets.

Primary trigger pattern:
- `execute ticket-1`
- `execute ticket-2`
- ...

Entry points:
- Hook map: `docs/pos/ai/commands.yaml`
- Execution protocol: `docs/pos/ai/execution-protocol.md`
- Ticket board: `docs/pos/ai/ticket-status.md`
- Ticket specs: `docs/pos/ai/tickets/`

Source planning docs:
- `docs/pos/current-pos-supported-brainstorm.md`
- `docs/pos/expected-ui-component-checklist.md`
